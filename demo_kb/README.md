# Демо-база знаний

Небольшой набор документов, права на публикацию которых подтверждены. Состав согласуется
с заказчиком; до согласования каталог пуст.

Рабочая база знаний в репозиторий не входит: она подключается через `KB_DIR`
(PDF + манифест `kb.yaml`, структура — `kb.example.yaml` в корне проекта), индекс — через `INDEX_DIR`.
